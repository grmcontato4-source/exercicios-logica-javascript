# Exercícios de Lógica em JavaScript

Esse repositório reúne exercícios que desenvolvi durante o curso técnico de ADS para praticar lógica de programação usando JavaScript.



- JavaScript
- HTML
- CSS

## Sobre os exercicios

Os exercícios trabalham conceitos básicos de programação e foram feitos para colocar em prática o que estava aprendendo durante as aulas.

Entre os exercícios estão cálculos, condicionais, repetições, comparações e outras atividades de lógica.

## O que pratiquei

- Variáveis
- Operadores
- Condicionais (if, else e else if)
- Estruturas de repetição
- Funções
- Entrada e saída de dados
- Cálculos e comparações
- Manipulação básica do HTML com JavaScript
